# Hi, I'm Elizabeth 👋

I'm a **Software Engineer** and **Computer Science & Linguistics student at UCLA** who enjoys building software that solves real-world problems.

I have experience developing full-stack web applications using **React, Node.js, Express, Supabase, PostgreSQL, and REST APIs**, with a growing focus on integrating **AI into everyday workflows**.

Most recently, I built a volunteer management platform for **Girls Who Math** that supports **20+ staff members** and **50+ volunteers**. The platform centralizes volunteer management, automates administrative tasks, and uses **Groq AI** to generate personalized outreach based on volunteer milestones, participation, and student feedback.

I'm passionate about creating software that is both technically sound and genuinely useful to the people who rely on it. Whether I'm building internal tools, researching new AI applications, or designing user-focused experiences, I enjoy turning complex problems into intuitive solutions.

## 🚀 Current Interests

- 🤖 AI-powered applications
- 🌐 Full-stack web development
- ⚛️ React & modern JavaScript
- 📊 Data-driven products
- 💙 Building technology that creates meaningful social impact
